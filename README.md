# Автомаслоф — сайт сервиса замены масла

Лендинг магазина автомасел и мастерской «Автомаслоф» в Кстово.

Публичная версия: https://maslo-kstovo.ru/

Основные направления:

- замена масла в двигателе;
- замена масла в АКПП, CVT и DSG;
- подбор и продажа масел, фильтров и технических жидкостей;
- предварительная запись в мастерскую.

## GitHub Pages

Статическая версия сайта автоматически собирается и публикуется в GitHub Pages
после каждого обновления ветки `main`.

Локальная сборка:

```bash
npm ci
npm run build:github-pages
```

Готовые файлы появятся в каталоге `gh-pages-dist`.

## Текущий статус

Онлайн-запись выполняется через Yclients: https://n1579356.yclients.com/.
На сайте установлен счетчик Яндекс Метрики `112114667` и передаются события:

- `yclients_booking` — переход к онлайн-записи;
- `phone_click` — нажатие на номер телефона;
- `route_click` — переход к построению маршрута;
- `reviews_click` — переход к отзывам на Яндекс Картах;
- `engaged_30s` — активный визит длительностью не менее 30 секунд.

Завершенные записи и этапы воронки формы передаются из Yclients после
подключения этого же счетчика в разделе «Интеграции → Аналитика».

Следующий этап — добавление политики обработки персональных данных и реальных
фотографий.
